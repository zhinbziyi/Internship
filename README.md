# 實習成果整理

本 Repository 整理實習期間參與及完成的實作成果，內容包含網頁開發、
自動化流程、需求分析、API 與資料庫實作，以及報表轉換工具等。

各項成果依主題整理於不同資料夾，詳細的功能、檔案結構與使用方式
可參考各專案說明及 Repository 內的完整說明文件。

## 成果總覽

| 項目 | 內容 | 主要技術 / 工具 |
| --- | --- | --- |
| 工時系統 | 需求文件整理、API 開發與資料庫實作 | .NET、REST API、JSON、SQL Server |
| n8n 自動化 | Webhook、天氣 API 串接與自動化流程 | n8n、OpenWeather API、JavaScript |
| 報表轉換工具 | 將 HTML Table 轉換並輸出為 PDF / Excel | HTML、JavaScript |

## 工時系統

以工時管理系統為主題，參與需求整理、API 與資料庫實作。

主要內容包含：
- 工項與 RA 文件整理
- 專案、子任務及工時紀錄等 API
- Request / Response DTO
- SQL Server 資料庫與測試資料

## n8n 自動化

使用 n8n 練習自動化流程與 Webhook 串接，並將外部 API 資料提供給前端網頁使用。

主要內容包含：
- 天氣查詢 Workflow
- OpenWeather API 串接
- Webhook 測試
- 天氣查詢前端
- n8n 與 LLM 整合練習

📁 [查看 n8n 自動化](./n8n自動化/)

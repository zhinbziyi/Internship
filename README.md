# 實習成果整理

本 Repository 整理實習期間參與及完成的實作成果，內容包含網頁開發、自動化流程、需求分析、API 與資料庫實作，以及報表轉換工具等。

各項成果依主題整理於不同資料夾，本頁以成果總覽為主，詳細內容可參考各項目的 README 與實習交接文件。

## 成果總覽

| 項目 | 內容 | 主要技術 / 工具 |
| --- | --- | --- |
| 工時系統 | 需求文件整理、API 開發與資料庫實作 | C#、REST API、JSON、SQL Server |
| n8n 自動化 | Webhook、天氣 API 串接與自動化流程 | n8n、OpenWeather API、JavaScript |
| 報表轉換工具 | HTML Table 預覽並輸出為 PDF / Excel | HTML、JavaScript |
| 新竹通 | 後台退費流程與使用案例整理 | Flowchart、Use Case |
| 貿協後台－E 化學院 | 工項與 RA 文件整理 | 需求分析、文件整理 |
| Frieren | JSON 資料運用與前端網頁實作 | HTML、CSS、JavaScript、JSON |

# 工時系統

實習期間參與工時系統的需求整理、API 規劃與開發，以及資料庫規劃與建置。

開發前先依系統需求整理相關工項與文件，並規劃 API 與資料庫結構，再進行後端 API 與資料庫實作。

## 專案內容

### 1. 工項與需求文件

依系統功能整理不同模組的工項與需求，包含：

- 專案管理
- 任務管理
- 任務視圖切換
- 彈窗操作

相關原始文件保留於 [`AI工項`](./AI工項/) 與 [`RA文件`](./RA文件/)。

### 2. API 規劃與開發

開發前先以試算表整理 API 規劃內容，再依規劃進行後端 API 實作。

API 開發過程使用 C#，並透過 Postman 進行功能測試。

📁 [查看 API 資料](./API/)

其中包含：
- API 規劃文件
- API 專案程式碼

### 3. 資料庫規劃與建置

依系統需求先以試算表規劃資料庫結構，再使用 SQL Server 進行資料庫建置。

資料夾內包含：

- 資料庫規劃文件
- 資料庫建立 SQL Script
- 實際工時索引
- 員工、專案、子任務及工時等測試資料

建立資料庫後加入測試資料，供後續 API 功能測試使用。

📁 [查看資料庫資料](./資料庫/)

### 4. 工時系統前端

資料夾內保留工時系統前端頁面，用於串接後端 API 並呈現專案、任務及工時等資料。

前端需搭配本專案的 API 與 SQL Server 資料庫使用，因此未提供獨立線上 Demo。

📁 [查看工時系統前端](./工時系統前端/)

## 使用技術 / 工具

- C#
- REST API
- JSON
- SQL Server
- Postman
- Google 試算表

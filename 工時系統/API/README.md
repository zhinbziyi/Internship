# 工時系統 API

本資料夾保存工時系統後端 API 的規劃文件與實作程式碼。

開發前先以試算表整理 API 的 Request、Response 與相關欄位，再依規劃進行 API 實作，並使用 Postman 進行功能測試。

## 檔案說明

- `API修改版.xlsx`：API 規劃文件
- `TimesheetSystem.zip`：工時系統 API 專案程式碼

## 開發工具 / 技術

- C#
- REST API
- JSON
- SQL Server
- Postman

## 執行說明

API 執行前需先建立對應的 SQL Server 資料庫並設定資料庫連線。

資料庫建立程式碼及測試資料可參考 [`../資料庫/`](../資料庫/)。
